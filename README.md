Smart Home Energy Analytics System
Overview

Smart Home Energy Analytics System is a desktop application developed using Java Swing and MySQL.

The system helps users:

Track electricity consumption
Manage appliances
Monitor energy usage
Calculate electricity costs
Generate reports
Predict monthly electricity bills
